# Denta — product card standard

This file is the mandatory checklist before creating or changing any product card.

## Sources and identity

1. Review the 1688 listing and the matching Dentiphoto listing together when both are available.
2. Use 1688 to lock the product’s physical identity: silhouette, proportions, controls, interfaces, markings, colour and complete set.
3. Use Dentiphoto to validate identity and to select additional verified angles and product facts.
4. For a product with a Dentiphoto listing, its gallery photos are approved reference material for creating the standard Denta PNG views. Preserve the exact model, proportions, controls, markings, colours and included accessories from those references. Useful original Dentiphoto angles may also remain in the gallery as supplemental views.
5. When 1688 does not provide downloadable images, use a browser screenshot of that listing as the reference image. Do not substitute a visually similar product.
6. Reject any generated image that changes geometry, adds or removes controls/accessories, bends the product, changes markings or conflicts with either source.

## Gallery requirements

1. Every gallery contains 3–5 useful, non-duplicate views.
2. Order: main full-product view; alternate/functional view; complete set within the first three; macro/detail; optional additional view.
3. Every final gallery asset is a PNG.
4. Default: use a genuine alpha-transparent PNG on the card gallery background (`#26211E`). Never place a white studio image, JPEG, RGB PNG with a white background or a screenshot directly in the gallery.
5. Exception: a full-kit image requiring contact shadows may be rendered as a complete PNG image on exactly `#26211E`; its outer pixels must match the gallery background. No white matte, halo, square or different gradient is allowed.
6. Check all four corners and the object edge at 100% scale before connecting a gallery asset.

## Shared layout

1. Use the C-SMART-I PILOT card as the structural reference: gallery at left; dark purchase panel at right; infographic, details, catalog CTA and shared footer below.
2. Keep the visual system unchanged: palette, rounded panels, typography, spacing, buttons and responsive behaviour.
3. Product content may vary, but the interface structure and styling must stay consistent.
4. The catalog tile and any home-page card must link to the correct product page.

## Final preflight

- [ ] Both sources checked, or an 1688 browser screenshot checked.
- [ ] 3–5 distinct PNG views are present.
- [ ] No white/background-bearing source image is connected.
- [ ] No product distortion or invented detail.
- [ ] Full-kit view included when the product has a kit.
- [ ] Product name, price, category, facts and package list match the verified source.
- [ ] Gallery looks seamless against `#26211E`.
- [ ] Local preview checked. Do not publish or push unless the user explicitly requests it.
